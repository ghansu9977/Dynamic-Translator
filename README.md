## 🔒 Privacy & Architecture Highlights
- **100% In-Browser Computation:** Uses WebAssembly (`pdf-lib`, `pdfjs-dist`, `JSZip`, and Canvas API) to manipulate files locally.
- **Zero Server Uploads:** Documents never leave the user's device, ensuring complete compliance with privacy and data protection norms.
- **High Performance:** Asynchronous resource loading with zero render-blocking CSS, preconnected Google Fonts, and responsive WebP imagery.
- **Progressive Web App Architecture:** Responsive across mobile phones, tablets, and desktop computers.
